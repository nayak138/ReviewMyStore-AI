# Role & Objective
You are an expert full-stack developer specializing in transactional email deliverability and HTML/CSS optimization. Your task is to refactor the current automated invitation email template to ensure it avoids the Gmail "Promotions" tab and lands in the user's "Primary" inbox. 

Follow strict deliverability best practices by shifting the layout from an aggressive, bulk-looking marketing style to a clean, transactional style.

---

## Technical & Architectural Requirements

### 1. HTML Structure & Layout
- **Left-Align the Layout:** Remove heavy wrapping wrappers that center all contents. Shift the entire email structure to a standard left-aligned layout, which mimics regular human-to-human corporate correspondence.
- **Minimize HTML Nesting:** Strip out complex table structures, nested `<div>` groups, or excessive `padding`/`margin` declarations that signal a heavy automated email compiler. Keep the DOM tree as shallow as possible.

### 2. Assets & Typography
- **Remove Large Graphic Visual Anchors:** Eliminate the large centered marketplace/brand icon (`<img>` block) from the body of the message. 
- **Subtle Branding Option:** If a logo is absolutely required by system design guidelines, reduce its size to a maximum height of `32px` and place it at the absolute top-left or bottom footer. Otherwise, favor plain-text branding.
- **Universal Fonts:** Use system font stacks (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`). Do not pull external Google Fonts or complex web fonts via `@import`.

### 3. Interactive Call-To-Action (CTA) Refactoring
- **Strip CSS Buttons:** Completely remove the stylized, rounded, background-colored CSS button block (`Accept invitation`).
- **Convert to Text Hyperlink:** Replace the button with a simple, standard inline blue hyperlink or an explicitly visible text URL (e.g., `[Accept Invitation](https://...)` or `<a href="...">Accept Invitation</a>`). 
- **Avoid URL Shorteners:** Ensure the anchor text points directly to the validated domain or transaction endpoint. Do not use tracking or redirection proxies.

### 4. Copywriting and Text Trigger Tweaks
- **Eliminate Promotional Urgency:** Scan the text copy and completely remove phrases simulating scarcity or timers (e.g., "This invitation will expire in 14 days"). 
- **Transactional Copy Focus:** Rewrite the copy to sound matter-of-fact and contextual. State what the application workspace is, who invited them, and what the immediate next step is without using high-pressure vocabulary.
- **Dynamic Personalization:** Inject placeholder variables for recipient personalization (e.g., `{{recipient_name}}`) to maximize personal context signals for spam filters.

---

## Output Expectations
1. Provide the updated, refactored inline HTML/CSS template code.
2. Ensure the code is strictly optimized for email clients (table-based where necessary for basic client safety, but visually reading as lightweight plain text).
3. List out a brief summary of the exact modifications made to the structure and text variables for review.
