## Start with your role

5-Star.AI uses an agency workspace and invitation model. Agency owners manage
organizations and team access. Invited teammates can work only with the active
businesses and features assigned to them.

There is no separate self-serve store-owner account type in the current app.
The store operations guide explains how an individual operator uses access
provisioned by their agency or workspace owner.
